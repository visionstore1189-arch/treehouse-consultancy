# Treehouse Consultancy website

A bilingual Next.js corporate website prepared for Cloudflare Pages Free. The public website exports to `out/`. Three enquiry forms use a separate Cloudflare Pages Function; the existing Mutabiq application remains separate.

**Delivery status:** the production build and Pages Function compile successfully. All 48 English and Arabic routes are generated. This is a tested local project, not a live Cloudflare deployment. Online forms and client login are intentionally unavailable until their external dependencies are configured. A working editorial CMS is outstanding.

## Start locally

Install Node.js 24 LTS with npm and Git. From this directory:

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`. The development server previews the website; it does not run Pages Functions. Keep `NEXT_PUBLIC_FORMS_ENABLED=false` initially.

To reproduce the production deployment locally:

```sh
npm run build
npm run preview
```

Open `http://localhost:8788`. This serves `out/` with the actual Cloudflare Pages Function runtime. Without configuration, a POST to `/api/enquiry` returns HTTP 503 and the UI clearly says enquiries are unavailable. Never use `next start` for this static export.

## Verify

```sh
npm run typecheck
npm test
npm run build
npm run cf:build
npm run check:links
```

The build includes an export check for the 48 required routes, language direction, canonical tags and hosting files. Security tests use SQLite and mocked Turnstile/email HTTP responses; they do not send email. The browser QA report distinguishes local tests from production checks still needed.

## Free architecture

No paid hosting plan, database plan, API or deployment service is required. The initial architecture uses Pages Free, Workers Free quotas for Pages Functions, D1 Free, Turnstile Free and Resend Free. Stay on the free plans; quotas are finite. The default `pages.dev` address needs no domain purchase. Domain registration, if the client does not already own the domain, is a separate client dependency.

No real client data, regulator library, passwords, MFA flow or subscription logic is published in this marketing site. No analytics or advertising trackers are active. Fonts are self-hosted. Arabic beyond the supplied launch paragraphs is a draft translation requiring a native regulatory professional's review.

The requested Emil Kowalski skills were installed and applied: restrained transform/opacity motion, clear press feedback, fine-pointer hover gating, reduced-motion fallback and interruptible interactions. Source licences of dependencies remain with their respective owners; the supplied logo and approved company copy remain client assets.
